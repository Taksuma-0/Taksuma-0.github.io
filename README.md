# taksuma-0.github.io

Página raíz de GitHub Pages para [mi-sii-mcp](https://github.com/Taksuma-0/mi-sii-mcp), el servidor MCP para el SII de Chile.

Existe para que los buscadores tengan el favicon, el nombre del sitio (`WebSite` en Schema.org) y el `robots.txt` en la raíz del dominio, que es donde los leen. El sitio del proyecto está en https://taksuma-0.github.io/mi-sii-mcp/.
